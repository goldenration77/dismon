About World Disaster Dashboard

A free, real-time global crisis monitor that aggregates natural and humanitarian disaster data onto an interactive map. Built as a single self-contained HTML file with zero backend and no API keys required.

Key Features

Interactive Leaflet map with clustering
Multiple basemap styles (Basic, Satellite, Dark, Greenlines)
Auto-refresh every 30 seconds
Type, severity & time-range filters
New-disaster toasts + subtle sound alert
Live related news headlines in popups
Live stats + frequency chart
Dark / Light + high-contrast modes
Offline cache + demo fallback
Fully responsive (mobile → desktop)

Data Sources

  • EMSC / CSEM – European-Mediterranean Seismological Centre (global earthquake catalog)
  • USGS – U.S. Geological Survey real-time earthquake feeds
  • GDACS – Global Disaster Alert and Coordination System (UN/EC) – severity-ranked multi-hazard alerts
  • NASA EONET – Earth Observatory Natural Event Tracker (fires, floods, storms, volcanoes…)
  • freenewsapi.ai – Keyless news search for related headlines

Map Types

  • Basic – OpenStreetMap street map
  • Satellite – Esri World Imagery
  • Dark Map – CartoDB Dark Matter (easy on the eyes at night)
  • Greenlines – OpenTopoMap (topographic / terrain with contour lines)
